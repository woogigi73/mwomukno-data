뭐 먹노? 개인정보처리방침

시행일 2026년 10월 4일

요약: 뭐 먹노?(친구·동료용 웹사이트)는 회원가입이 없고, 개인정보를 수집하거나 개발자 서버로 보내지 않습니다. 위치는 휴대폰 안에서 주변 식당을 계산하는 데만 쓰입니다.

1. 수집하는 개인정보

이 사이트는 이름, 전화번호, 이메일, 계정 등 어떤 개인정보도 수집하지 않습니다. 로그인 기능이 없고, 광고·분석 도구도 들어 있지 않습니다.

2. 위치정보의 이용

  • 사용자가 브라우저의 위치 권한을 허용한 경우에만, 사이트를 쓰는 동안 현재 위치를 확인합니다.
  • 현재 위치에서 도보 거리 안의 식당을 고르는 계산은 모두 휴대폰 안에서 이루어집니다.
  • 위치 좌표를 개발자나 제3자에게 전송하거나 저장하지 않습니다. 개발자는 별도의 서버를 운영하지 않습니다.
  • 사이트는 현재 위치 주변 시·군·구의 공개 식당 데이터 파일을 내려받습니다. 이 파일은 GitHub Pages(깃허브)에서 제공되며, 내려받을 때 인터넷 이용에 따른 일반적인 접속 정보(IP 주소 등)가 GitHub의 정책에 따라 처리될 수 있습니다.
  • 위치 권한을 허용하지 않아도 지역을 직접 골라 쓸 수 있습니다.

3. 이 브라우저에만 저장되는 정보

최근 방문한 식당 기록(일주일 내 방문한 곳을 후보에서 빼기 위해), 단골로 표시한 식당, 숨긴 식당, 화면 설정을 이 브라우저의 저장소(localStorage)에만 저장합니다. 이 정보는 외부로 전송되지 않으며, 설정의 "방문 기록·단골 지우기"를 누르거나 브라우저의 사이트 데이터를 지우면 삭제됩니다.

4. 외부 서비스 연결

사용자가 "카카오맵에서 보기", "길찾기", "공유하기", "전화", "커피 한 잔(후원)" 버튼을 누를 때에만 해당 서비스(카카오맵, 메신저, 전화, 토스·카카오페이 등)를 엽니다. 이후의 정보 처리는 해당 서비스의 정책을 따릅니다.

5. 사용하는 기능

  • 위치(허용한 경우, 사이트 사용 중에만): 주변 식당 계산
  • 동작 센서(허용한 경우): 폰을 흔들어 뽑기
  • 인터넷: 같은 사이트의 공개 식당 데이터 파일 내려받기

6. 데이터 출처

식당 정보는 행정안전부 지방행정 인허가 공공데이터(일반음식점·휴게음식점·모범음식점)를 가공한 것이며, 카카오맵 장소 연결 정보를 함께 사용합니다. 공공데이터 특성상 실제 영업 상태와 차이가 있을 수 있습니다.

7. 아동의 개인정보

이 사이트는 개인정보를 수집하지 않으므로 아동의 개인정보도 수집하지 않습니다.

8. 문의

개인정보 관련 문의는 문의 게시판으로 보내 주세요.

9. 방침 변경
